# NOTHING OS 🎯

### Project Description

NOTHING OS is an interactive virtual desktop designed to be completely useless — but surprisingly fun.
It combines a futuristic interface, mouse-reactive elements, animations, and uniquely designed mini-games with different gameplay mechanics.

### The Problem (that doesn't exist)

People have too many useful websites.

There is absolutely no website that wastes your time in a beautifully designed and completely unnecessary way.

### The Solution (that nobody asked for)

We created **NOTHING OS**, a useless virtual operating system where the user can interact with a central core and launch completely pointless mini-games.

The games don't solve any real problem — they just provide an entertaining way to waste a few minutes while experiencing animations, physics, memory challenges, reactions, and random interactions.

## Technical Details

### Technologies/Components Used

For Software:

- **HTML5** – Website structure and game interfaces
- **CSS3** – Styling, animations, gradients, glassmorphism and visual effects
- **JavaScript (ES6+)** – Game logic, interactions and animations
- **DOM API** – Dynamic creation and manipulation of game elements
- **Browser Mouse & Keyboard Events** – User interaction and controls
- **requestAnimationFrame()** – Smooth real-time animations and physics effects
- **VS Code** – Development environment
- **GitHub** – Source code hosting and version control
- **Vercel** – Website deployment and hosting

For Hardware:

- Not applicable – this is a software-only project.
